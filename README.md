## 💼 Project 1: E-Commerce GRC Foundation

### Project Overview
This project establishes foundational **Governance, Risk, and Compliance (GRC) artifacts** for a mock E-Commerce Startup, demonstrating the ability to move from identifying threats to implementing organizational policy.

### 1. Risk Register & Mitigation Plan
This artifact demonstrates the fundamental process of identifying, analyzing, and treating risks within a cloud-hosted e-commerce environment.

#### **Methodology**
* **Risk Assessment:** Used a qualitative matrix (Low/Medium/High) to prioritize common E-commerce risks.
* **Control Mapping:** Mitigation controls were mapped directly to **CompTIA Security+** concepts (MFA, EDR) and aligned with the **NIST Cybersecurity Framework** (Identify and Protect Functions).

### 2. Access Control Policy
This policy was created as a direct response to the "Unauthorized Account Takeover" risk identified in the Risk Register. It establishes the organizational rules to enforce strong authentication and the Principle of Least Privilege.

#### **Key Elements**
* Defines requirements for **Multi-Factor Authentication (MFA)** and **Role-Based Access Control (RBAC)**.
* Includes a control mapping section to **NIST SP 800-53** (AC family) to ensure compliance alignment.
